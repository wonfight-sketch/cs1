Google News RSS edition

1. Upload all files including .github/workflows/update-news.yml to a GitHub repository.
2. In Actions run Update government press releases manually once.
3. Check that news.json contains at least 5 items.
4. Connect Netlify to this GitHub repository to deploy and redeploy on changes.
5. RSS scheduled three times daily, timing is best effort.

Note: Google News is NOT the korea.kr government press release feed and does not meet a strict korea.kr-only requirement. Google News RSS usage may be restricted to personal/noncommercial feed readers; review terms before public use.
